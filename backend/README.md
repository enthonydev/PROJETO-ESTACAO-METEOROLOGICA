# Backend

Backend Python/FastAPI responsável por ingestão, validação, persistência e exposição dos dados da estação.

## Organização prevista
- `app/api/`
- `app/core/`
- `app/models/`
- `app/schemas/`
- `app/services/`
- `app/repositories/`
- `tests/`

A implementação deve respeitar o contrato de telemetria versionado e a arquitetura aprovada.
