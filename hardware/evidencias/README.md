# Evidências de hardware

**Estado atual:** SEM EVIDÊNCIA FÍSICA.

Este diretório receberá somente evidências realmente produzidas durante a validação: fotos da montagem, logs de boot/serial, scan I²C, leituras, vídeos quando úteis, resultados observado × esperado, falhas, correções, retestes, calibração, integração e testes de campo.

Cada registro futuro deve identificar:

- ID do teste;
- versão do código;
- data/hora e ambiente;
- componentes e modelos;
- procedimento;
- resultado esperado e observado;
- responsável;
- classificação **FÍSICA** ou **SIMULADA**;
- limitações e arquivos associados.

Não inserir fixtures, screenshots de testes de software ou desenhos conceituais neste diretório como se fossem evidência física. A ausência de arquivos neste momento é intencional.
