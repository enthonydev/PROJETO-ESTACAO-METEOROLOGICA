# Hardware

Área responsável pela documentação e pelos artefatos físicos da estação.

## Organização
- `diagrams/`: diagramas elétricos e de interligação.
- `wokwi/`: arquivos e instruções de simulação.
- `datasheets/`: índice/referências dos datasheets efetivamente utilizados; evitar duplicar material protegido quando um link oficial for suficiente.
- `evidencias/`: registros organizados de testes físicos e simulados.
- `pinout.md`: pinagem validada do projeto.
- `bom.md`: lista de materiais.

Esta estrutura deve ser alimentada conforme as tasks do projeto forem validadas. Não registrar como concluído hardware ainda não testado.
