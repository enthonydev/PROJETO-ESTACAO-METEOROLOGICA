# Política de Segurança

Este é um projeto acadêmico em desenvolvimento. Somente o estado mais recente da `main`, após revisão, é considerado suportado.

## Credenciais e segredos

Nunca versionar senhas, tokens, chaves de API, credenciais de Wi-Fi, strings de conexão ou dados pessoais. Arquivos de exemplo devem conter apenas nomes de variáveis e valores fictícios.

## Relato

Vulnerabilidades ou exposições acidentais de credenciais devem ser comunicadas diretamente aos responsáveis pelo projeto antes de qualquer divulgação pública. Não publicar segredos em Issues ou Pull Requests.

## Dependências

Dependências de firmware, backend e frontend devem ser registradas conforme forem efetivamente utilizadas. Alterações com impacto em contratos ou arquitetura seguem o fluxo normal de revisão.
